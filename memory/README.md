# memory/ の地図

AIの記憶の置き場。索引 `MEMORY.md` は作業場の `CLAUDE.md` から毎回読み込まれる。

## 1ファイルの形

```
---
name: 英小文字とハイフンの短い名前（ファイル名と同じ）
description: 1行の要約。あとで「この記憶を開くか」を決める時に読む
type: feedback（直された・認められたやり方）／user（本人のこと）／project（進行中の仕事の前提）／reference（外の資料の場所）
---

事実を1つ。

**Why:** なぜそうするか（直された時の出来事があれば、それも）
**How to apply:** いつ・どう使うか
```

## 決まり

- 1つの記憶に1つの事実。
- 同じ話の記憶が既にあれば、新しく作らずにそれを直す。
- 間違いだと分かった記憶は、本人に見せてから消す。
- 書いたら `MEMORY.md` に `- [題](ファイル名.md) — 一言` の形で1行足す。
