READMEに進み具合や状態を書かない。

**Why:** READMEに進み具合を書くと、ゴールファイルと二重になり、どちらかが必ず古くなる。古いREADMEを信じたAIが、終わったゴールに書き込みに行くこともある。
**How to apply:** README には、何の領域か、中にどんな情報がどう入っているか、その領域で作業する時のコツだけを書く。進み具合・状態・決めたことは `goals/` のゴールファイルへ。ゴールの本文からフォルダを指す（逆向きにはしない）。

出どころ：三上の型（2026-09-25）
