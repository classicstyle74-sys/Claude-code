# マルニ 週次インテリジェンス収集アプリ

日本の百貨店ビジネスに活かすための「マルニ（MARNI）」関連情報を、
毎週自動で収集・整理してフォルダに格納する Claude Code スキルです。

## 📦 構成

```
.claude/skills/marni-weekly/   ← スキル本体
├── SKILL.md                   ← 収集・整理の手順書
├── config.yaml                ← 検索キーワード設定（ここを編集して調整）
└── templates/                 ← レポートテンプレート

reports/marni-weekly/          ← 収集結果の格納先
├── INDEX.md                   ← 全週の索引
└── 2026-W28/                  ← 週ごとのフォルダ（ISO週番号）
    ├── README.md              ← 週次サマリー（最初に読む1枚）
    ├── 01-brand-news.md       ← ブランド公式動向
    ├── 02-sns-buzz.md         ← SNS・話題（Twitter/X由来の話題を含む）
    ├── 03-dept-store.md       ← 百貨店業界動向
    ├── 04-competitors.md      ← 競合・ラグジュアリー市場
    ├── 05-consumer-trends.md  ← 消費者・トレンド
    └── sources.md             ← 参照URL一覧
```

## 🚀 使い方

Claude Code のセッションで以下のように依頼するだけです:

```
/marni-weekly
```

または「今週のマルニレポートを作って」と話しかけても起動します。
今週分のフォルダが作成され、レポート一式が生成・格納されます。

## ⏰ 自動実行

毎週月曜 9:00（JST）に自動でレポートを生成する Routine（スケジュール実行）を
設定できます。設定・停止はセッションで依頼してください:

- 設定: 「週次レポートの自動実行を設定して」
- 停止: 「週次レポートの自動実行を止めて」

## 🔧 カスタマイズ

`.claude/skills/marni-weekly/config.yaml` の `queries` を編集すると、
収集対象のキーワード・カテゴリを変更できます（例: 特定店舗名、催事名の追加）。

## 📝 注意

- Twitter/X の生データには直接アクセスできないため、SNSの話題は
  ニュース記事・まとめメディア経由で収集しています。
- 情報の捏造を避けるため、出典URLのない情報はレポートに記載しません。
