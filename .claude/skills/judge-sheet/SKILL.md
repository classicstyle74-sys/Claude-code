# 判断シート

本人に決めてもらう時は、文章の中に論点を埋めず、1枚のシートにして見せる。
論点と選択肢が一覧になっていれば、本人は読み解かずにその場で決められるから。

## シートの中身（論点ごと）

| 欄 | 書くこと |
| --- | --- |
| 論点 | 何を決めるか（Q1, Q2…） |
| 選択肢 | 2〜4個。推奨を最初から選んだ状態にする |
| それぞれで何が変わるか | 選んだ後に起きることを1行ずつ |
| 推奨と理由 | 1つに決めて、理由を1行 |
| 回答欄 | 選択肢に無い答えを本人の言葉で書ける欄を必ず残す |

## 出し方（上から順に、できるもの）

1. **Artifact のページ**（本人だけが見られる）。推奨を選んだ状態のラジオボタンと自由記入欄を置き、「答えをコピー」ボタンで `Q1: …／Q2: …` の形の答えを作って、会話に貼ってもらう。見本：`inbox/判断シート-初期設定.html`。
2. ページが出せない時は、`inbox/判断シート-<題>.html` に同じ1枚を書き、ブラウザで開いてもらう。
3. それも無理なら、会話に表で出す（`AskUserQuestion` が使える時はそれでもよい。推奨を先頭に置き「(Recommended)」を付ける）。

## 答えを受け取ったら

- 本人に同じ答えを二度書かせない。
- 答えを、関係するゴールファイルの「ノート」の「決めたこと」に、理由と日付つきで書く。
- 日誌 `days/YYYY-MM-DD.md` に1行足す。
