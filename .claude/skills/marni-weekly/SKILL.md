# マルニ 週次インテリジェンス収集スキル

日本の百貨店ビジネスに活かすための「マルニ（MARNI）」関連情報を1週間分収集し、
見やすいレポートとしてフォルダに格納する。

## 実行手順

### 0. 準備

1. `config.yaml`（このスキルと同じフォルダ）を読み、検索カテゴリとキーワードを確認する。
2. 今日の日付から **ISO週番号** を求め、出力フォルダを決める:
   - 例: 2026-07-11 → `reports/marni-weekly/2026-W28/`
   - 対象期間は「その週の月曜〜日曜」。レポートに明記すること。
3. フォルダが既に存在する場合は上書き更新（同じ週の再実行＝最新化）とする。

### 1. 情報収集（WebSearch / WebFetch を使用）

`config.yaml` の各カテゴリごとに、記載されたクエリで WebSearch を実行する。
1カテゴリにつき2〜3クエリ、期間指定（直近1週間・「2026年7月」など年月付き）を意識する。

- 検索結果のうち、**対象週に関係が深いもの・百貨店ビジネスに示唆があるもの**を優先。
- 重要な記事は WebFetch で本文を確認し、要点を正確に把握する。
- Twitter/X の生データには直接アクセスできないため、SNSの話題は
  「Togetter・ニュース記事・トレンドまとめ・ファッションメディアのSNS言及記事」経由で拾う。
- 古い情報（対象週より前）は「背景情報」として扱い、新規性のある情報と区別する。

### 2. フォルダへの格納

対象週フォルダに以下のファイルを作成する（テンプレートは `templates/` を参照）:

```
reports/marni-weekly/2026-W28/
├── README.md              ← 週次サマリーレポート（これが本体・最初に読む1枚）
├── 01-brand-news.md       ← マルニブランドの公式動向・新作・コラボ
├── 02-sns-buzz.md         ← SNS・口コミ・話題（Twitter/X由来の話題を含む）
├── 03-dept-store.md       ← 日本の百貨店業界の動向（売上・施策・インバウンド）
├── 04-competitors.md      ← 競合ブランド・OTBグループ・ラグジュアリー市場
├── 05-consumer-trends.md  ← 消費者トレンド・ファッショントレンド
└── sources.md             ← 参照したURL一覧（カテゴリ別）
```

各カテゴリファイルの形式:
- 見出し＋3〜7件のトピック。各トピックは「事実の要約（2〜4文）」＋「出典URL」＋
  「💡 百貨店ビジネスへの示唆（1〜2文）」のセットで書く。
- 収集できなかったカテゴリは「今週は特筆すべき動きなし」と正直に書く（捏造しない）。

### 3. 週次サマリーレポート（README.md）

`templates/report-template.md` の構成に従い、以下を含める:
- 対象期間・作成日時
- **今週のハイライト3〜5点**（最重要事項の箇条書き）
- **アクション提案**（売場・仕入れ・販促に対する具体的な提案2〜4点）
- カテゴリ別ダイジェスト（各ファイルへの相対リンク付き）

### 4. 見やすいHTMLダッシュボード（任意だが推奨）

`templates/` を参考に、同フォルダへ `dashboard.html` を生成する。
- 自己完結型（外部CDN・外部画像なし）、ダーク/ライト両対応
- ハイライト・カテゴリ別カード・アクション提案を1画面で見られる構成

### 5. 索引の更新

`reports/marni-weekly/INDEX.md` に今週の行を追記する（新しい週が上）:

```
| 週 | 期間 | ハイライト（1行） | リンク |
```

### 6. コミット＆プッシュ

自動実行（Routine）から起動された場合は、生成物をコミットして
指定ブランチへプッシュする。手動実行の場合はユーザーの指示に従う。

## 注意事項

- 情報の捏造・出典のない数値の記載は厳禁。不確かな情報は「未確認」と明記。
- 日本語でレポートを書く。ブランド名・固有名詞は原文表記を併記してよい。
- 過去週のフォルダは変更しない（アーカイブとして保全）。
