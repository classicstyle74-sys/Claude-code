# チャート選択ガイド（Chart Selection Guide）

スライドごとの「推奨チャートまたはレイアウト」を出すときの選択基準。
原則：**チャートはメッセージの証拠**。タイトル（結論）を証明する形を選ぶ。

## メッセージ → チャート早見表

| 伝えたいメッセージ | 推奨チャート | 補足 |
|---|---|---|
| 前年より増えた/減った | 2本の比較バー（LY vs TY） | 差分を数字で明記 |
| 何が増減に効いたか | ウォーターフォール | LY → 要因 → TY のブリッジ |
| トレンドが変わった | 折れ線（月次推移 + LY点線） | 転換点に注釈を置く |
| KPIの構造 | KPIツリー図 | 各ノードにvs LYを併記 |
| 店舗間の差 | 横棒（降順ソート） | 平均線を入れる。晒し上げ配色にしない |
| 構成比の変化 | 100%積み上げバー（2本） | 円グラフ2つ並べより比較しやすい |
| 2指標の関係（例：RTW構成比×ATV） | 散布図 | 店舗をプロット、傾向線を添える |
| 顧客セグメントの増減 | セグメント別ウォーターフォールまたは対比バー | New増とLost増を同時に見せる |
| アクションプラン | チャートではなく3カラムカード | 誰が・何を・いつまでに・KPI |
| リスク | 3列テーブル（リスク/影響/対応） | 最大3行 |
| ロードマップ | 横軸時間のマイルストーン図 | H2なら月単位 |

## スライドレイアウトの原則

1. **1スライド1チャート**が基本。2つ以上必要ならスライドを分ける
2. タイトル（結論）→ チャート → 下部にFact / Insight / Actionの順
3. チャート内の強調は1箇所だけ（結論に対応する系列・バーのみ色を変える）
4. 凡例より直接ラベル。読み手に視線移動をさせない
5. 軸の単位・期間・データソースを必ず明記する

## オーディエンス別の調整

- **店長会**：シンプルな比較バー中心。散布図・ウォーターフォールは口頭説明前提でのみ
- **経営層**：1資料に合計3〜4チャートまで。詳細はAppendixへ
- **HQ**：KPIツリー、ウォーターフォール、散布図など分析的なチャートを許容
- **百貨店・外部**：双方メリットの模式図、共同施策のロードマップ中心。内部KPIの生数字は出しすぎない
- **店舗スタッフ**：チャートより行動リスト・トーク例。使うなら1枚に1つの簡単な棒グラフまで

## やってはいけないこと

- 3D円グラフ、二重軸の乱用、虹色配色
- 1枚に4つ以上のチャートを詰め込む
- 結論と関係ないチャートを「データがあるから」載せる
- 軸の切り取りで差を誇張する（信頼を失う）
