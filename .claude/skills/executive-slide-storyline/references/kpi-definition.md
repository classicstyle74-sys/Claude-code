# KPI定義と分解ロジック（KPI Definition Guide）

このスキルで扱うリテールKPIの定義。ユーザーのデータを整理するとき、
およびKPI decompositionスライドを作るときに参照する。
ブランド・会社によって定義が異なる場合は、ユーザーの定義を優先する。

## 基本KPIツリー

```
Revenue（売上）
  = TR（Transactions：購入件数）
  × ATV（Average Transaction Value：平均客単価）

ATV
  = UPT（Units Per Transaction：1件あたり購入点数）
  × AP（Average Price：平均商品単価）

参考：Quantity（販売点数）= TR × UPT
```

## 各KPIの定義と読み方

| KPI | 定義 | 上がる/下がる主な要因 |
|---|---|---|
| Revenue | 期間売上 | 下位KPIの掛け算。必ず分解して読む |
| Revenue vs LY | 前年同期比 | ベースの成長性 |
| Revenue vs Budget | 予算比 | 計画に対する進捗 |
| TR | 購入件数（トランザクション数） | トラフィック、転換率、顧客リテンション |
| ATV | 売上 ÷ TR | UPT、AP、カテゴリミックス |
| UPT | 販売点数 ÷ TR | クロスセル・スタイリング提案力 |
| AP | 売上 ÷ 販売点数 | 価格改定、商品ミックス（RTW比率など） |
| Quantity | 販売点数 | TR × UPT |

## カテゴリ・構成比

- **RTW**（Ready-to-Wear）：ウェア。一般に高単価でATV/APを押し上げる。
  提案難易度が高く、店舗の提案力の差が出やすい
- **ACC**（Accessories）：バッグ・小物等。入口商品になりやすい
- **RTW構成比**：RTW売上 ÷ 総売上。店舗提案力の代理指標として使うことが多い

## 顧客セグメント

| セグメント | 一般的な定義（要確認） | 見るべき数字 |
|---|---|---|
| New | 期間内に初回購入した顧客 | 人数、初回ATV、リピート率 |
| Loyal | 継続購入している既存顧客 | 人数、頻度、年間支出 |
| Lost | 一定期間購入がない既存顧客 | 人数、失った年間売上、上位リスト |
| High / Top / Super Top | 年間支出額の閾値による階層（ブランド定義） | 人数 vs LY、金額 vs LY、1人あたり支出 |

※ Lostの定義期間（12ヶ月/18ヶ月等）と High/Top/Super Top の閾値は
必ずユーザーに確認する。推測しない。

## 日本市場特有の用語

- **外商（Gaisho）**：百貨店の外商部門。上位顧客を担当し店外でも販売する。
  HQ向け資料では "department store external sales (gaisho)" として
  必ず一言の説明を添える
- **DSR**（Daily Sales Report）：店舗の日次レポート。数字だけでなく
  「誰が・何を・どこまでやったか」の行動記録として使うのがこのスキルの前提
- **百貨店インショップ**：百貨店内の店舗。集客・催事・外商連携が業績に影響する

## KPI読み解きの定石

1. Revenueが良くても必ずTR × ATVに分解する。ATV上昇がTR減を隠すことが多い
2. TR減は「トラフィック減」か「転換率低下」か「Lost顧客増」かを切り分ける
3. ATV上昇は「値上げ（AP）」か「提案力（UPT）」かを切り分ける
4. 店舗差は立地・トラフィックのせいにする前に、RTW構成比とUPTを比較する
5. ハイスペンダーは「人数」と「1人あたり金額」を分けて見る
