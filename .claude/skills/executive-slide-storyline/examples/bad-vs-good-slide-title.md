# 結論型スライドタイトル Bad vs Good 集

タイトルは「項目名」ではなく「結論」。
タイトルだけを上から読んでストーリーが通じるかが判定基準。

## 実績・KPI系

| Bad（項目名） | Good（結論型） |
|---|---|
| Sales result | Revenue grew slightly, but transaction recovery remains the key issue |
| 1-6月実績 | 売上は前年超え。ただし成長はATV依存で、TRの弱さが残る |
| KPI analysis | ATV growth offset the decline in transactions |
| KPI分解 | 落ちているのはTR。ATVの上昇が課題を見えにくくしている |
| Monthly trend | Traffic softness started in April and has not recovered |
| Budget vs Actual | 予算未達はQ2と百貨店インショップに集中している |

## 店舗系

## 見分け方チェック

- タイトルに動詞（〜した、〜が要因、〜すべき）が入っているか
- タイトルだけ読んで「So what?」に答えられるか
- 「分析」「結果」「一覧」「について」で終わるタイトルは項目名 → 書き直す
