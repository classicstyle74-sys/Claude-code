# AI ニュース日次ダイジェスト

YouTube・X・Web 上の AI 関連情報を収集し、`ai-news/YYYY-MM/YYYY-MM-DD.md`
に日本語のダイジェストを保存するスキル。

## 手順

### 1. 収集期間の決定

- 基本は「直近 36 時間」(前日の取りこぼし防止のため 24h より広め)。
- ユーザーが期間を指定した場合 (「今週の」など) はそれに従う。
- 同じ日付のダイジェストが既に存在する場合は上書きせず、既存の内容に
  新しい情報を追記・マージする。

### 2. YouTube の新着動画を取得

スキル内のスクリプトを実行する (API キー不要、RSS ベース):

```bash
python3 .claude/skills/ai-news-digest/scripts/fetch_youtube.py --hours 36
```

- 対象チャンネルは `sources.json` の `youtube_channels` で管理。
- JSON で新着動画一覧 (チャンネル名・タイトル・URL・公開日時・概要) が返る。
- `errors` に失敗が含まれていても、取得できた分でダイジェストを作る。

**フォールバック**: 実行環境のネットワークポリシーによっては youtube.com
への直接アクセスが遮断される (`Tunnel connection failed: 403` が全件出る)。
その場合はスクリプトを再試行せず、WebSearch で代替する:

- `"<チャンネル名>" YouTube 新着動画` や、話題の動画を報じる記事を検索する。
- ダイジェストの YouTube セクションに
  「⚠️ この環境では YouTube に直接アクセスできないため、検索ベースの
  情報のみ」と注記する。

### 3. X (Twitter) の話題を収集

X は API なしで直接取得できないため、WebSearch を使って間接的に収集する:

1. `sources.json` の `x_accounts` にある主要アカウントについて、
   `"<アカウント名>" X post 発表` のような検索で直近の注目ポストを探す。
2. `search_keywords` の各キーワードで検索し、X 上で話題になっている
   AI トピック (バズっている発表・デモ・議論) を拾う。
3. 検索結果からポスト本体の URL (x.com/...) が分かる場合はそれを、
   分からない場合は報じている記事の URL を出典として記録する。

### 4. Web ニュースで補完

WebSearch で「AI ニュース 今日」「AI news today」等を検索し、
YouTube / X で拾えなかった大きな発表 (新モデル、資金調達、規制など) を補完する。

### 5. ダイジェストを書く

出力先: `ai-news/YYYY-MM/YYYY-MM-DD.md` (フォルダがなければ作成)

テンプレート:

```markdown
# AI ニュースダイジェスト — YYYY年M月D日(曜)

> 収集期間: MM/DD HH:MM 〜 MM/DD HH:MM (JST) / 収集元: YouTube, X, Web

## 🔥 今日のハイライト

その日最も重要なニュース 1〜3 件を、それぞれ 2〜3 文で要約。

## 📺 YouTube 新着動画

| チャンネル | タイトル | 公開 |
|---|---|---|
| Two Minute Papers | [動画タイトル](URL) | 7/11 09:00 |

注目動画には表の下に 1〜2 文の補足を付ける。

## 💬 X での話題

- **[トピック名]** — 何が話題か 1〜2 文。 ([出典](URL))

## 📰 その他のニュース

- **[見出し]** — 1 文要約。 ([出典](URL))

## 📝 所感

全体の流れを 2〜3 文でまとめる (任意)。
```

執筆時のルール:

- すべて日本語で書く (固有名詞・製品名は原語のまま)。
- 各項目に必ず出典リンクを付ける。リンク切れ URL を創作しない —
  検索・取得で実際に確認した URL のみ使う。
- 事実と推測を区別する。未確認の噂は「未確認」と明記。
- 該当情報がないセクションは「本日は特になし」と書き、セクション自体は残す。

### 6. インデックスを更新

`ai-news/README.md` に新しいダイジェストへのリンクを追記する
(新しい日付が上)。ファイルがなければ以下の形式で作成:

```markdown
# AI ニュースアーカイブ

- [2026-07-11](2026-07/2026-07-11.md) — その日のハイライト 1 行
```

### 7. コミット

git リポジトリ内であれば、生成・更新したファイルを
`Add AI news digest for YYYY-MM-DD` としてコミットする (プッシュは
ユーザーの指示またはセッションの慣例に従う)。

## カスタマイズ

- 収集元の追加・削除: `sources.json` を編集
  (YouTube はハンドル `@xxx` を追加するだけでよい。チャンネル ID は
  スクリプトが自動解決してキャッシュする)。
- ユーザーが「〇〇チャンネルも追加して」と言ったら `sources.json` を
  更新してから収集を実行する。

## 毎日自動で実行するには

このスキル自体はオンデマンド実行。毎日の自動実行はスケジューラと
組み合わせる:

- Claude Code on the web / Cowork: Routine (トリガー) を
  「毎朝 8 時に /ai-news-digest を実行」のように作成する。
- CLI 環境: OS の cron などから `claude -p "/ai-news-digest"` を実行する。

ユーザーが「毎日自動でやって」と依頼した場合は、利用可能な
スケジューリング機能でトリガーを作成する。
